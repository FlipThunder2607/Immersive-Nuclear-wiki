# Immersive Nuclear wiki

Wiki of [Immersive Nuclear](https://github.com/FlipThunder2607/Immersive-Nuclear), an Immersive Engineering addon for Minecraft 1.12.2.

**Read it here:** https://flipthunder2607.github.io/Immersive-Nuclear-wiki/

Machines, items and fluids of each production line, with an interactive flow chart, 3D models of the machines and the recipes. The wiki is in Portuguese for now.

It is a static site: open `index.html` in a browser, no server needed.
